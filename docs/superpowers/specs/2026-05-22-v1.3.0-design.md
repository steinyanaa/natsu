## 1. Preset Chinese Book Sources

### Goal
Let users add curated book sources in one click rather than typing URLs manually.

### Design
- New file `src/onlineSources/presets.ts` — static array of `BookSourcePreset` objects:
  ```ts
  export interface BookSourcePreset {
    id: string;
    name: string;
    kind: "opds" | "rss";
    url?: string;           // undefined = user must supply URL
    requiresUserUrl: boolean;
    description: string;
  }
  ```
- **Bundled presets:**
  | id | name | kind | url | requiresUserUrl |
  |----|------|------|-----|-----------------|
  | `wenku8` | 轻小说文库 | opds | `http://www.wenku8.net/modules/article/articlelist.php?fullflag=1` | false |
  | `standard-ebooks` | Standard Ebooks | opds | `https://standardebooks.org/opds` | false |
  | `zlibrary` | zlibrary（镜像） | opds | — | true |

- **UI:** "预设书源" chip row above the custom source list in SettingsPanel → OnlineSourcesSection. Each chip shows name + "+" icon. On click:
  - If `requiresUserUrl = false`: directly adds to user's source list, chip grays out with ✓
  - If `requiresUserUrl = true`: opens an inline input dialog for the user to paste their current mirror URL, then adds
- Activated presets show ✓ indicator; can still be deleted from the source list normally
- No network call at preset-add time; source is fetched only when user actively searches

### Files
- `src/onlineSources/presets.ts` (new)
- `src/onlineSources/PresetsRow.tsx` (new) — chip strip component
- `src/settings/OnlineSourcesSection.tsx` (modified) — embed `<PresetsRow>`

## 2. RSS/Atom Manual Refresh

### Goal
Support RSS/Atom feeds as a book source type (e.g., sites that publish epub download links via feed).

### Design
- Extend `BookSource` type:
  ```ts
  kind: "opds" | "rss"
  ```
- New `src/onlineSources/rssAdapter.ts`:
  - `fetchRssFeed(url: string): Promise<BookSearchResult[]>`
  - Uses `fetch()` + browser `DOMParser` to parse XML
  - Handles both RSS 2.0 (`<item>`) and Atom (`<entry>`)
  - Extracts: `title`, `author`, `link`, `enclosure` (epub attachment), `pubDate`
  - Maps to `BookSearchResult` (same shape as OPDS results)
- Online source search: when source `kind === "rss"`, call `rssAdapter` instead of OPDS adapter
- The existing "刷新" button triggers a re-fetch; no background polling
- Add source UI: "类型" selector with options `OPDS` / `RSS·Atom Feed`
- Error handling: feed parse failure → show inline error banner in source results area

### Files
- `src/onlineSources/rssAdapter.ts` (new)
- `src/onlineSources/opdsAdapter.ts` (modified) — split shared types to `src/onlineSources/types.ts`
- `src/types.ts` (modified) — `BookSource.kind` union extended
- `src/settings/OnlineSourcesSection.tsx` (modified) — add type selector

## 3. Highlight / Note Export (Markdown + Anki TSV)

### Goal
Let users export all annotations for a book in two formats: Markdown (for notes apps) and Anki TSV (for flashcard import).

### Design
- New `src/export/annotationExporter.ts`:
  ```ts
  exportMarkdown(bookId: string): Promise<string>
  exportAnkiTsv(bookId: string): Promise<string>
  ```
  - **Markdown format:**
    ```markdown
    # 书名 — 笔记导出

    ## 第1章 章节名

    > 高亮文本内容

    *用户笔记（若有）*

    ---
    ```
  - **Anki TSV format** (tab-separated, importable directly):
    ```
    正面（高亮句）\t背面（笔记 + 「书名·章节」）
    ```
  - Queries `annotations` table grouped by `chapterIndex`, sorted by `cfi`
- UI: book detail card (or reader top-bar `⋯` menu) → "导出笔记" button → bottom sheet with two options: **Markdown** / **Anki TSV**
- Calls `window.readerApi.saveFile(content, suggestedFilename)` → triggers native Save dialog
- Main process: add `saveFile` IPC handler using `dialog.showSaveDialog` + `fs.writeFile`

### Files
- `src/export/annotationExporter.ts` (new)
- `src/export/ExportSheet.tsx` (new) — bottom sheet component
- `src/electron/preload.ts` (modified) — expose `saveFile`
- `src/electron/main.ts` (modified) — `saveFile` IPC handler
- `src/reader/ReaderScreen.tsx` (modified) — wire "导出笔记" menu item

## 4. Cover Auto-Fetch (OpenLibrary + Google Books)

### Goal
Automatically retrieve cover art for books that lack an embedded cover image.

### Design
- New `src/metadata/coverFetcher.ts`:
  ```ts
  fetchCover(meta: { isbn?: string; title: string; author?: string }): Promise<string | null>
  // returns base64 data-URL or null
  ```
  - Strategy 1 (if ISBN present): `https://covers.openlibrary.org/b/isbn/{isbn}-L.jpg` — direct image, no auth required
  - Strategy 2 (title + author): Google Books API `https://www.googleapis.com/books/v1/volumes?q=intitle:{title}+inauthor:{author}` — no API key for basic thumbnail; take `volumeInfo.imageLinks.thumbnail`, upgrade from `http` to `https`, swap `&zoom=1` to `&zoom=3` for larger image
  - Fetch result → convert to base64 → store in `books.coverData`
- Trigger points:
  1. `importBook()` end: non-blocking `fetchCover(...).then(...)` — failure is silent
  2. Book shelf right-click context menu → "重新抓取封面" — shows loading spinner on tile
- ISBN extraction: attempt to parse from epub metadata `dc:identifier` (already read during import)

### Files
- `src/metadata/coverFetcher.ts` (new)
- `src/db.ts` (modified) — add `updateBookCover(id, base64)` helper
- `src/App.tsx` (modified) — call `fetchCover` after import, wire right-click menu item
- `src/bookshelf/BookTile.tsx` (modified) — loading state for cover refresh

## 5. Reading Statistics Enhancement

### Goal
Add three new views to the existing stats panel: a GitHub-style heat-map calendar, a reading speed display, and a 30-day trend curve.

### Design

#### 5a. Heatmap Calendar
- `src/stats/HeatmapCalendar.tsx` — pure SVG, 52-week grid (Sunday columns)
- Color buckets from `--md-sys-color-primary` at varying opacities:
  | Minutes | Shade |
  |---------|-------|
  | 0 | `surface-container` |
  | 1–15 | primary @ 25% |
  | 16–45 | primary @ 55% |
  | 46+ | primary @ 90% |
- Hover tooltip: "2026-05-22 · 读了 32 分钟"
- Data: query `reading_sessions` grouped by date (`DATE(started_at)`)

#### 5b. Reading Speed
- `src/stats/speedTracker.ts`:
  - `recordPageTurn(chapterCharCount: number, elapsedMs: number)` — called from TextPane on page turn
  - Stores a rolling 10-sample buffer in memory; persists session average to `reading_sessions.avg_wpm`
  - `getWeeklyAvgWpm(): number` — average of all sessions in past 7 days
- Display: stat card "本周平均 xxx 字/分钟" in StatsPanel header row
- `reading_sessions` table: add `avg_wpm INTEGER` column (migration via `IF NOT EXISTS` ALTER)

#### 5c. History Curve (30 days)
- `src/stats/ReadingCurve.tsx` — pure SVG polyline, no external chart library
- X-axis: last 30 days labels (every 5th day); Y-axis: 0 → max daily minutes (auto-scaled)
- Smooth curve via SVG cubic bezier control points
- Same data source as heatmap; reuse the grouped-by-date query result (passed as prop)

#### Integration
- `src/StatsPanel.tsx` (modified) — embed all three components, share the date-grouped data fetch

### Files
- `src/stats/HeatmapCalendar.tsx` (new)
- `src/stats/ReadingCurve.tsx` (new)
- `src/stats/speedTracker.ts` (new)
- `src/StatsPanel.tsx` (modified)
- `src/db.ts` (modified) — `getSessionsByDate()` query helper, `avg_wpm` migration
- `src/reader/TextPane.tsx` (modified) — call `speedTracker.recordPageTurn` on page advance

## 6. Code / Architecture Cleanup

### Goal
Reduce `App.tsx` (~1731 lines) and `TextPane.tsx` (~1513 lines) to focused files by extracting well-bounded hooks and sub-components. No behavior changes.

### App.tsx Target: ≤ 400 lines

| Extract to | Responsibility |
|-----------|---------------|
| `src/app/useLibrary.ts` | Book CRUD: `importBook`, `deleteBook`, `updateBookMeta`, library array state |
| `src/app/useReaderNavigation.ts` | `openBook`, `closeBook`, `openingCoverRect` state, `currentBook` |
| `src/bookshelf/useBookShelf.ts` | Sort/filter state, search query, grouped-books memo |

`App.tsx` retains: top-level state wiring + root JSX layout only.

### TextPane.tsx Target: ≤ 600 lines

| Extract to | Responsibility |
|-----------|---------------|
| `src/reader/usePageTurn.ts` | `nudgePage`, curl animation state, pageTurnStyle branching |
| `src/reader/useDictionary.ts` | `selectionText`, `dictWord`, popover position state, `onLookup` handler |
| `src/reader/useEpubChapter.ts` | Chapter HTML fetch, font injection, drop-cap class logic |

`TextPane.tsx` retains: component JSX composition, scroll/resize effects, rendering engine interface.

### Rules
- No public API changes: all hooks/components used by other files must preserve their existing props/return shapes
- Each new file ≤ 250 lines
- No new dependencies introduced
- Refactor is purely file-boundary changes; TypeScript types unchanged

### Files (all new hooks, modified callers)
- `src/app/useLibrary.ts` (new)
- `src/app/useReaderNavigation.ts` (new)
- `src/bookshelf/useBookShelf.ts` (new)
- `src/reader/usePageTurn.ts` (new)
- `src/reader/useDictionary.ts` (new)
- `src/reader/useEpubChapter.ts` (new)
- `src/App.tsx` (modified — shrunk)
- `src/reader/TextPane.tsx` (modified — shrunk)

## Non-Goals (v1.3.0)

- Background RSS polling / push notifications
- zlibrary hard-coded domain (too volatile; user-supplied URL only)
- New chart library dependency (stats use pure SVG)
- Any changes to epub/pdf/comic rendering engines
- New IPC channels beyond `saveFile`
