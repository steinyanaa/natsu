# EPUB 漫画阅读指南

本文说明 Natsu 对扫描版 / 固定版式 EPUB 漫画的处理方式，以及推荐设置。

## 适用范围

当 EPUB 中大多数章节是固定版式页面（例如 Kmoe 扫图本、图片页 EPUB）时，Natsu 会把它识别为 manga EPUB，并在 `TextPane` 中启用漫画布局规则。

## 推荐设置

打开 **设置 → 漫画布局**：

| 设置 | 适合场景 |
| --- | --- |
| 单页 | 一次看一张图，适合键盘或触控翻页 |
| 双页 | 横屏阅读日漫/扫图本，对开页显示 |
| 条漫 | Webtoon / 长图连续阅读 |

### 双页模式

- 建议开启“首页单独占位”，让封面独占一页，后续页正确成对。
- 双页 spread 会以同一高度显示左右两页，不再因为图片比例不同而上下错位。
- 懒加载按 spread 作为整体判断：只要对开页任一半接近视口，两半都会一起渲染。

### 按键翻页自动对齐

设置项：**按键翻页后自动对齐到下一页**

- 开启：保留 scroll-snap，对键盘翻页后自动吸附到页面起点。
- 关闭：取消 manga EPUB 的 scroll-snap，键盘翻页改为约一屏的即时跳转，减少 smooth scroll 和 snap 回弹叠加造成的晕动感。

### Paged 阅读模式

普通文本 EPUB 仍然支持 **Scroll / Paged** 阅读模式。

但扫描版 manga EPUB 会始终用滚动模式渲染，因为文本分页模式依赖 CSS columns，会破坏固定版式图片页和双页布局。

### 条漫模式

条漫模式会去掉相邻章节之间的分隔线、顶部/底部 padding、强制最小高度，以及 inline 图片基线留白。相邻图片应尽量无缝衔接。

## 验证建议

1. 用同一本扫图 EPUB 分别测试单页、双页、条漫布局。
2. 双页模式确认：封面单页居中，后续对开页等高，边界附近不会出现半边模糊占位。
3. 关闭“按键翻页后自动对齐到下一页”，确认键盘翻页不再出现二段动画。
4. 切换全局阅读模式到 Paged，确认 manga EPUB 仍然稳定滚动，普通文本 EPUB 仍可分页。
